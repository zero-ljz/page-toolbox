# 全局工具箱

一个运行在 Tampermonkey 等用户脚本管理器中的单文件网页工具箱。通过可拖动的悬浮球，可以快速使用文本翻译、聚合搜索、二维码生成、页面编辑和解除复制限制等功能。

当前版本：`2.2.1`

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或其他兼容的用户脚本管理器。
2. 点击 [安装全局工具箱](https://raw.githubusercontent.com/zero-ljz/page-toolbox/main/page-toolbox.user.js)。
3. 在用户脚本管理器中确认安装并刷新网页。

脚本使用 `*://*/*` 匹配 HTTP 和 HTTPS 页面，也可能在匹配的 iframe 中运行。

## 使用方法

- 点击悬浮球打开或关闭工具箱。
- 拖动悬浮球调整位置，位置会自动保存。
- 左键点击工具执行功能，右键点击可收藏或取消收藏。
- 在面板顶部输入名称搜索工具。
- 拖动工具按钮调整同一分类中的顺序。
- 悬浮球不可见时，可从用户脚本管理器菜单打开工具箱、设置或重置位置。

护眼模式、暗黑模式和网页编辑可再次点击切换状态。翻译整页、解除限制、显示密码和屏蔽元素等操作没有完整的撤销机制，需要刷新页面恢复。

## 自定义搜索

打开“脚本设置”，在“自定义搜索列表”中填写 JSON 数组。每一项包含 `name`、`url`，`icon` 可选。

```json
[
    {
        "name": "Google",
        "icon": "🔎",
        "url": "https://www.google.com/search?q=%s"
    },
    {
        "name": "GitHub",
        "icon": "",
        "url": "https://github.com/search?q=%s"
    }
]
```

支持以下占位符：

| 占位符 | 内容 |
| --- | --- |
| `%s` | 页面选中的文本；未选择时提示输入 |
| `%host%` | 当前页面域名 |
| `%url%` | 当前页面完整地址 |

`icon` 留空时，脚本会根据搜索地址自动获取网站图标。2.2.1 会将自定义名称和图标内容用于面板 HTML，请只导入自己检查过并信任的配置。设置保存后可按提示刷新页面应用。

## 权限与外部服务

| 权限 | 用途 |
| --- | --- |
| `GM_registerMenuCommand` | 注册工具箱、设置和重置命令 |
| `GM_xmlhttpRequest` | 请求 Google 和微信翻译接口 |
| `GM_getValue` / `GM_setValue` | 保存设置、悬浮位置、收藏和排序 |
| `GM_addStyle` | 注入工具箱样式 |
| `GM_setClipboard` | 复制屏幕取色结果 |
| `GM_info` / `GM_openInTab` | 2.2.1 已声明，当前功能未直接使用 |

使用翻译功能时，待翻译文本会发送到对应的第三方翻译服务。自动网站图标由 `p.252525.xyz` 代理获取。“网页标注”仅在点击后从 unpkg 加载 Spacing.js。

脚本通过 `@require` 加载：

- GM_config：设置界面。
- qrcode `1.4.4`：二维码生成。

“执行 JS”会直接运行选中或输入的代码，不会再次确认。请只执行自己理解并信任的内容。

## 开发

项目保持单文件结构：[page-toolbox.user.js](./page-toolbox.user.js) 同时是源码和可安装文件，不需要构建步骤。

修改后至少执行语法检查：

```powershell
node --check .\page-toolbox.user.js
```

发布新版本时，需要同步更新脚本元数据中的 `@version` 和 README 的当前版本。修改收藏或排序逻辑时，需要兼容已经按工具名称保存的数据。

## 已知限制

- 翻译依赖第三方非官方接口，可能受到网络、频率限制或接口变更影响。
- 整页翻译会逐个处理文本节点，不支持中止、恢复原文或动态内容跟踪。
- 通用暗黑模式基于颜色反转，复杂页面的显示效果可能不理想。
- 解除限制会注册持续到页面刷新的事件监听器，可能影响部分页面交互。
- 屏蔽元素没有撤销功能，功能提示中的 `Esc` 取消尚未实现。
- EyeDropper API 需要浏览器支持，并且只能由用户主动操作触发。
